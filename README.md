# RISC-V Project

A RISC-V assembly program that translates binary commands into BMP vector graphics output. This project demonstrates low-level graphics generation using RISC-V assembly language.

## Overview

This project was developed during the Winter 2023 semester at Warsaw University of Technology (WUT) as part of the computer architecture coursework. It showcases the implementation of vector graphics generation at the assembly level.

## Features

- Converts binary commands to BMP format
- Generates vector graphics output
- Written in pure RISC-V assembly
- Low-level graphics manipulation

## Technical Details

The program is written in RISC-V assembly language (100% Assembly) and handles binary-to-BMP conversion for vector graphics generation.
